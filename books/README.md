# Books — библиотека книг для работы с нейросетями

Хранилище технических книг, приведённых к виду, удобному для консультаций с AI-агентами:
компактные карты-оглавления + полные тексты глав в Markdown + точечный поиск через grep.
Без RAG и векторных баз — только файлы и агентный поиск (INDEX → grep → чтение куска).

## Структура

```
originals/                      # нетронутые исходники (epub и т.п.)
library/
  <book-slug>/                  # проработанная версия книги
    metadata.yaml               # метаданные (генерируется)
    INDEX.md                    # карта глав и секций (генерируется) — точка входа
    topics.md                   # кураторская карта «вопрос → главы» (ручная)
    glossary.md                 # глоссарий книги (генерируется)
    chapters/*.md               # по файлу на главу, с YAML frontmatter
    assets/                     # картинки и диаграммы из текста
.opencode/
  skills/book-ingest/           # скилл: как добавлять новые книги
    SKILL.md
    scripts/epub_to_md.py       # конвертер epub -> markdown (stdlib, без зависимостей)
```

## Как консультироваться с книгой (протокол для агента)

Принцип — **progressive disclosure**: сначала компактные карты, тяжёлый текст — только точечно.

1. Прочитай `library/<book>/INDEX.md` — компактная карта глав/секций и размеры.
2. Уточни тему по `library/<book>/topics.md` — там типовые инженерные вопросы → главы и секции.
3. Найди конкретное место: `grep <фраза> library/<book>/chapters/` — grep возвращает `файл:строку`.
4. Прочитай только кусок файла вокруг нужной строки (offset/limit), а не главу целиком.
5. В ответе ссылайся на источник: книга, глава, секция.

Если тема размыта — читай секцию `Summary` нужной главы (~500 слов) и решай, углубляться ли.

## Как добавить книгу

Скажи агенту «добавь книгу <файл>» — сработает скилл `book-ingest`
(см. `.opencode/skills/book-ingest/SKILL.md`). Кратко: epub кладётся в `originals/`,
конвертер делает `library/<slug>/`, агент проверяет результат и пишет `topics.md`.

## Правила

- `originals/` не изменяется никогда.
- `chapters/`, `INDEX.md`, `glossary.md`, `metadata.yaml` — генерируются; правки руками потеряются
  при ре-инжесте. Исправления вносятся правкой скрипта и повторным прогоном.
- `topics.md` — ручной артефакт, ре-инжест его не трогает.
- Книги — легальный контент владельца репозитория; не публиковать репозиторий публично.
